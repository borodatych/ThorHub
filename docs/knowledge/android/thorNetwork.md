# СЕТЬ THOR И ЗАГРУЗКИ GAMENATIVE

**Наблюдение 15.11.2026:** с Thor (домашняя сеть, Россия) `downloads.gamenative.app` не отвечает:
IPv6 недоступен (ENETUNREACH), IPv4 соединяется, но данные не идут
Запасной `pub-…r2.dev` отвечает `200`, но отдаёт рывками и рвётся
С Mac тот же сервер качает нормально, с GitHub Releases Thor качает около 2,6 МБ/с

**Почему GameNative «висел» на загрузке:** Java пробовала IPv6 30 с на каждый адрес, таймаут чтения был 5 минут,
до запасного источника дело не доходило

**Что сделано в ThorHub:** IPv4 первым, соединение 5 с, зависание чтения 20 с, перебор трёх источников,
третий — релиз `mirror` в `borodatych/ThorHub` (имя файла: путь на сервере, `/` → `__`)

**Как обновлять зеркало:** список адресов — манифест GameNative и `assets/*.json` плюс имена из кода,
скрипт `/Volumes/Storage/Caches/ThorHub/mirror-fetch.sh`, затем `gh release upload mirror`
